# #2 Control de Trabajos

**Tipo:** App web (MVP)
**Estado:** Completo

## Qué hace

Herramienta de gestión de clientes y trabajos para técnicos y autónomos de servicios (fontaneros, electricistas, instaladores, etc.). Permite registrar trabajos, hacer seguimiento de clientes y gestionar el estado de cada encargo.

## Contenido


## Stack

React + Vite + Tailwind (frontend). Persistencia local o backend ligero (ver README interno del ZIP).

## Uso

Descomprimir el ZIP y seguir el README interno.
