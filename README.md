# Control de Trabajos

MVP de gestión de clientes y trabajos para técnicos y autónomos de servicios (fontaneros, electricistas, instaladores, etc.).

## Qué hace

Registro de trabajos, seguimiento de clientes y estado de cada encargo — pensado para quien vive gestionando avisos y presupuestos sin un sistema real detrás.
